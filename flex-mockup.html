B1 · Text only
  • + เร็วสุด · 1-2 ชม.
  • + message ส่ง 1 ฟอง · เบาสุด
  • − Format ดูจืด · ไม่มี brand identity
  • − 3 voices ปนกันอ่านยาก
B2 · Flex Cards ⭐
  • + Brand-feel เต็ม · ดูสวย
  • + 3 voices แยกชัดเจน
  • + ใช้สีตาม voice (เหมือนเว็บ)
  • − Setup นานกว่า · 2.5 ชม.
B3 · Hybrid
  • + Best UX — แก้ทุก trade-off
  • + User เลือกเองว่าอ่านสั้น/ยาว
  • − Setup ยาว · 5-6 ชม.
  • − Flex JSON ซับซ้อน · maintain ยากขึ้น

💡 คำแนะนำ: เริ่ม B2 ก่อน — ดี balance ที่สุด ใช้สีตาม voice ที่ user คุ้นเคยจากเว็บ · ถ้า user ขอ "อ่านสั้น" ภายหลัง ค่อย upgrade เป็น B3
