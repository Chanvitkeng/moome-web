📋 Steps · setup ใน LINE OA Manager

  1. Download PNG — กดปุ่มเขียวด้านบน · ได้ไฟล์ moome-richmenu-v2-2500x1686.png
  2. เปิด manager.line.biz/account/@262zpsua/richmenu
  3. คลิก "สร้างใหม่" (Create) — ถ้ามี Rich Menu เดิม สามารถ "ใช้" อันใหม่แทน
  4. Template: เลือก "Large" → "2 × 2" (4 ช่องเท่ากัน)
  5. ตั้งชื่อ Title: Moome Menu V2 · Display name: เมนู Moome
  6. Upload PNG ที่ download มา
  7. Set Actions สำหรับแต่ละ zone:
    ZoneActionURL / Text
    A · CalculateLinkhttps://moome.app/calculate.html
    B · MatchLinkhttps://moome.app/match.html
    C · TodayLinkhttps://moome.app/today.html
    D · Ask AI ⭐Linkhttps://liff.line.me/2009970211-9UWwksI6
  8. Save + Apply — เมนูจะอัพเดททันทีในแชท Moome OA
